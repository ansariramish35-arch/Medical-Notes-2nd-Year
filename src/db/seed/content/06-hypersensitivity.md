## 1. Definitions

:::definition Standard definition
**Hypersensitivity** is an **exaggerated or inappropriate immune response** to an antigen, which results in **tissue damage** rather than protection. The antigen involved is called an **allergen** when it triggers Type I reactions.
:::

:::definition Atopy
A genetic tendency (familial) to mount **IgE-mediated** responses to common environmental allergens — asthma, allergic rhinitis, atopic dermatitis ("the atopic triad").
:::

## 2. Gell and Coombs Classification (1963)

{{figure:hypersensitivity-types}}

| Type | Name | Mediator | Mechanism in one line | Timing | Prototype examples |
| --- | --- | --- | --- | --- | --- |
| **I** | Anaphylactic / Immediate | **IgE** | IgE-coated mast cells degranulate on allergen cross-linking | **Minutes** | Anaphylaxis, bronchial asthma, hay fever, urticaria |
| **II** | Cytotoxic | **IgG/IgM** | Antibody against cell-surface or matrix antigen → complement/phagocyte destruction | Hours | Transfusion reactions, HDN, autoimmune haemolytic anaemia, Goodpasture syndrome |
| **III** | Immune-complex | **IgG complexes** | Circulating Ag–Ab complexes deposit → neutrophilic vasculitis | Hours (3–10 h) | Serum sickness, Arthus reaction, SLE, post-streptococcal GN |
| **IV** | Delayed / Cell-mediated | **T cells** (CD4 Th1, CD8) | Cytokine-mediated macrophage activation or direct cytotoxicity | **24–72 h** | Mantoux test, contact dermatitis, graft rejection, TB granuloma |

:::highyield The one line examiners want first
Types I, II and III are **antibody-mediated**; Type IV is **cell-mediated** and is the only **delayed** type.
:::

## 3. Type I Hypersensitivity in Depth (LAQ expansion)

### Cells and players
- **IgE** produced against allergen → binds **FcεRI** on mast cells and basophils (**sensitization**).
- Re-exposure: allergen **cross-links two adjacent IgE molecules** → mast-cell degranulation.

### Mediators — the two-wave model

```flow
Allergen cross-links IgE on sensitized mast cell
↓
IMMEDIATE (minutes): preformed granule mediators — HISTAMINE, tryptase, heparin, ECF
↓
Histamine: vasodilation, ↑ permeability, bronchospasm, mucus
↓
LATE PHASE (hours): newly synthesized lipid mediators — LEUKOTRIENES (LTC4/D4/E4 = SRS-A), PROSTAGLANDIN D2, PAF + cytokines (IL-4, IL-5, IL-13, TNF)
↓
Eosinophil and neutrophil infiltration → sustained tissue damage
```

| Mediator | Main effect |
| --- | --- |
| Histamine | Vasodilation, vascular permeability, bronchospasm, pruritus |
| Leukotrienes C4/D4/E4 (SRS-A) | Prolonged bronchoconstriction, mucus |
| Prostaglandin D2 | Bronchospasm, vasodilation |
| PAF | Platelet activation, bronchospasm |
| IL-4 / IL-13 | IgE class switching |
| IL-5 | Eosinophil recruitment |

### Systemic vs local
- **Anaphylaxis** (systemic): injected/absorbed antigen → bronchospasm, laryngeal oedema, shock; **adrenaline (epinephrine) IM is the immediate treatment**.
- **Local:** asthma, allergic rhinitis, urticaria, food allergy.

### Diagnosis
- Skin prick test, serum total/specific IgE, radioallergosorbent test (RAST), eosinophil count.

:::why WHY? — Why is adrenaline life-saving in anaphylaxis?
Adrenaline's α1 effect reverses vasodilation and oedema (raises BP, shrinks mucosa); β2 effect bronchodilates and also stabilizes mast cells. It physiologically **opposes every histamine effect** within minutes.
:::

## 4. Type II — Antibody-Mediated Cytotoxicity

Five mechanisms (enumerate):
1. **Complement-mediated lysis** — transfusion reactions, HDN.
2. **Antibody + complement/opsonin-mediated phagocytosis** — autoimmune haemolytic anaemia.
3. **Antibody-mediated inflammation** — Goodpasture syndrome (anti–type IV collagen), rheumatic fever cross-reaction.
4. **Cellular dysfunction without damage** — Graves disease (TSH-receptor stimulation), myasthenia gravis (ACh-receptor blockade).
5. **Drug-induced** — penicillin/methyldopa coating RBCs.

## 5. Type III — Immune-Complex Disease

```flow
Antigen in excess → small soluble Ag–Ab (IgG) complexes
↓
Not cleared → deposit in vessels, glomeruli, joints, skin
↓
Complement activation (C3a, C5a) → neutrophil chemotaxis
↓
Neutrophils release lysosomal enzymes → vasculitis / GN / arthritis
```

| Model | Setting |
| --- | --- |
| **Arthus reaction** | Localized — intradermal injection into a hyperimmune individual (peak 3–8 h) |
| **Serum sickness** | Systemic — foreign serum/drugs: fever, urticaria, arthralgia, lymphadenopathy, GN (7–14 days) |
| Disease examples | SLE, polyarteritis nodosa, post-streptococcal GN, farmer's lung (extrinsic allergic alveolitis) |

## 6. Type IV — Delayed (Cell-Mediated) Hypersensitivity

Four subtypes (enumerate):
1. **Tuberculin-type (CD4 Th1)** — Mantoux test; induration peaks at **48–72 h**; IFN-γ-activated macrophages.
2. **Contact dermatitis (CD4/CD8)** — haptens (nickel, poison ivy, PPD) on skin; eczematous reaction 24–72 h.
3. **Granulomatous inflammation** — persistent intracellular organisms (TB, leprosy, sarcoidosis) → epithelioid cells, giant cells, granuloma.
4. **T-cell cytotoxic (CD8)** — type 1 diabetes, some graft rejection, viral hepatitis hepatocyte killing.

:::source Difference-question support
"Differentiate Type IV from Types I–III" → antibody vs T cell; minutes/hours vs 24–72 h; histamine/complex vs cytokines; skin test: prick (Type I) vs Mantoux (Type IV).
:::

## 8. Commonly Confused Concepts

| Confusion | Distinction |
| --- | --- |
| Type II vs Type III | Type II: antigen is **fixed** on a cell/matrix; Type III: complexes are **circulating** and deposit |
| Type I vs Type IV skin tests | Prick test = immediate wheal-and-flare (IgE); Mantoux = induration at 48–72 h (T cells) |
| Serum sickness vs Arthus | Systemic vs localized Type III |
| Anaphylatoxins vs chemotaxin | C3a/C5a = anaphylatoxins; C5a additionally = chemotaxin |
