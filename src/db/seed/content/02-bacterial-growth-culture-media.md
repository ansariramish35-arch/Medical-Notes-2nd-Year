## 1. Bacterial Growth and Reproduction

:::definition Exam definition
**Generation time (doubling time)** is the time required for a bacterial population to double during the log phase. Bacteria reproduce by **binary fission** — one cell divides into two identical daughter cells.
:::

- Growth = increase in **numbers**, not size (a population phenomenon).
- Measured by viable counts (colony-forming units), total counts, or turbidity.
- Generation time examples: *E. coli* ≈ 20 min; *M. tuberculosis* ≈ 18–24 h (which is why tuberculous cultures take weeks).

{{figure:growth-curve}}

### The Four Phases of the Batch Growth Curve

| Phase | What happens | Exam significance |
| --- | --- | --- |
| **Lag** | Cells enlarge, synthesize enzymes; no division | Adaptation to the new medium |
| **Log (exponential)** | Constant binary fission; most metabolically active | Generation time measured here; **β-lactams most effective**; cells most susceptible to adverse agents |
| **Stationary** | Nutrient depletion + toxic products; growth rate = death rate | Spore formation begins; secondary metabolites |
| **Decline (death)** | Death exceeds growth; involution forms | Viable count falls progressively |

:::why WHY? — Why are β-lactams most active in the log phase?
Penicillins block **transpeptidation** during NEW wall synthesis. Only actively dividing cells are building wall — and killing additionally requires concurrent autolysin activity. Stationary-phase cells are not synthesizing wall, so the drug has nothing to interrupt.
:::

## 2. Enumeration — Classification of Culture Media

:::source "Enumerate the culture media with examples." — give the COMPLETE list as category → purpose → example. Never "etc."
:::

**A. By consistency**

| Type | Composition | Use | Example |
| --- | --- | --- | --- |
| Liquid (broth) | No agar | Enrichment, biochemical tests | Nutrient broth |
| Semi-solid | 0.5% agar | **Motility**, microaerophilic culture | Motility medium |
| Solid | 2% agar | Isolation of colonies | Nutrient agar |

**B. By composition / function**

| Type | Purpose | Example |
| --- | --- | --- |
| Basal | Grow non-fastidious organisms | Nutrient agar/broth |
| **Enriched** | Added blood/serum for fastidious organisms | **Blood agar**, **chocolate agar** |
| **Selective** | Inhibitors suppress unwanted flora | MacConkey (bile salts inhibit Gram-positives), LJ, TCBS, DCA |
| **Indicator (differential)** | Distinguish organisms by colony appearance | MacConkey (lactose fermenters pink), blood agar (haemolysis) |
| **Enrichment** | Liquid; favours pathogen over commensals in faeces | Selenite F broth, tetrathionate broth |
| **Transport** | Maintain viability without multiplication | Stuart's medium, alkaline peptone water, buffered glycerol saline |
| Anaerobic | Reduced oxygen | Robertson's cooked meat medium, thioglycollate broth |

**C. Special media (exam favourites)**

| Medium | Organism |
| --- | --- |
| Lowenstein–Jensen (LJ) | *Mycobacterium tuberculosis* |
| TCBS | *Vibrio cholerae* — yellow sucrose-fermenting colonies |
| Bordet–Gengou / Regan–Lowe | *Bordetella pertussis* |
| Tellurite blood agar | *Corynebacterium diphtheriae* — black colonies |
| Chocolate agar + CO2 | *Neisseria*, *Haemophilus* |
| Sabouraud dextrose agar (SDA) | Fungi |
| Wilson–Blair | *Salmonella Typhi* |

## 3. Oxygen Requirements (Enumeration)

| Category | Requirement | Protective enzymes | Example |
| --- | --- | --- | --- |
| Obligate aerobes | O2 mandatory | Catalase + superoxide dismutase (SOD) | *M. tuberculosis*, *Pseudomonas* |
| Obligate anaerobes | O2 toxic | Lack catalase/SOD | *Clostridium*, *Bacteroides* |
| Facultative anaerobes | Grow with or without O2 | Possess both enzymes | *E. coli*, most pathogens |
| Microaerophiles | Low O2 (5–6%) | — | *Campylobacter*, *Leptospira* |
| Capnophiles | Need raised CO2 (5–10%) | — | *Brucella*, *Neisseria* |

## 4. Anaerobic Culture Methods (SN support)

- **Media:** Robertson's cooked meat medium (unsaturated fatty acids + glutathione consume O2), thioglycollate broth.
- **Jar methods:** McIntosh–Fildes jar / GasPak (H2 + CO2 generated; palladium catalyst); anaerobic glove box.
- **Indicator of anaerobiosis:** reduced methylene blue (colourless when anaerobic).

## 5. High-Yield and Exam Framework

:::highyield High-yield one-liners
- Growth curve phases: **lag → log → stationary → decline**; antibacterials hit the **log** phase.
- MacConkey is BOTH selective AND differential — examiners ask "classify MacConkey".
- Blood agar shows **haemolysis** (α, β, γ) — a differential property.
- Transport media keep organisms alive but do **not** allow multiplication.
- Motility is tested in **semi-solid** medium (0.5% agar).
:::

**SN framework — "Write a short note on culture media":** define → classify by consistency (table) → classify by function (table, one example each) → three special media → one line on transport media → complete.

**SAQ framework — "Define generation time / growth curve":** definition + four phases named + one line each.
